# Lab 3D

Lab 3D is a catalogue of 3D experiments. Open a Gaussian splat in the
viewer. Inside Mnemosyne OS it also opens the library of 3D objects and
the engine that turns a video into one.

## What it does

- **Viewer** — drop a `.splat` / `.spz` / `.ply` scene, turn it, walk
  inside it.
- **Objects & places** (Mnemosyne OS) — browse the 3D library on this
  machine, open a version on the stage.
- **Create** (Mnemosyne OS) — film an object or a place, then build the
  3D mesh with the host engines.
- **Decor & paintings** — place relief and wall art in a scene.

## Install

1. Get [Mnemosyne OS](https://mnemosyne-os.io/download).
2. In MnemoHub, paste this repository URL, or install from the store
   once the listing is live.
3. Open **Lab 3D** from the dock.

The viewer also runs alone in a browser (`pnpm dev` in this folder).
Create, Objects and Decor need Mnemosyne OS.
